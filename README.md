## نظرة عامة

نظام ERP/POS محاسبي محلي متكامل للبقالات ومحلات بيع الجملة، يربط المبيعات والمشتريات والمخزون والعملاء والموردين والديون والصندوق والمصروفات والأرباح والتقارير والصلاحيات في منظومة مالية واحدة قابلة للتدقيق.

### المبدأ الأساسي
> كل حركة مالية لها مصدر، مرجع، مالك (مستخدم)، طابع زمني، تؤثر على الـ Ledger الصحيح، وقابلة للتدقيق.

## المميزات الرئيسية

### ✅ يعمل بالكامل Offline
لا يحتاج إنترنت بعد التثبيت. جميع البيانات محفوظة محلياً عبر SQLite.

### ✅ محاسبة دقيقة
- تكلفة البضاعة المباعة (COGS) محسوبة بدقة
- التكلفة المرجحة (Weighted Average Cost)
- الربح الإجمالي والتشغيلي
- منع أخطاء floating-point باستخدام Decimal

### ✅ معاملات ذرية (Atomic Transactions)
كل عملية بيع/شراء/سداد تنفذ كمعاملة واحدة:
- إنشاء الفاتورة + العناصر + حركات المخزون + النقد/الدين + Audit Log
- إذا فشل أي جزء → Rollback كامل (لا فقدان للبيانات)

### ✅ نظام صلاحيات حقيقي
- 7 أدوار افتراضية
- 43 صلاحية موزعة على 10 وحدات
- فُرض على مستوى المنطق (وليس الواجهة فقط)

### ✅ سجل تدقيق كامل (Audit Log)
كل عملية حساسة مسجلة مع: المستخدم، الإجراء، التاريخ، القيم القديمة/الجديدة.

### ✅ دعم العربية و RTL
- واجهة عربية كاملة من اليمين لليسار
- دعم الوضع الفاتح والداكن

### ✅ نسخ احتياطي واستعادة محلي
- إنشاء نسخ JSON
- استعادة مع نسخة أمان قبل الاستعادة
- سجل النسخ السابقة

## الوحدات الرئيسية

### 1. لوحة التحكم (Dashboard)
- مبيعات/مشتريات/مصروفات اليوم
- صافي الربح اليومي
- رصيد الصندوق المتوقع
- ديون العملاء والموردين
- قيمة المخزون
- أصناف ناقصة

### 2. الكاشير (POS)
- بحث سريع بالاسم/الباركود/SKU
- شبكة منتجات بألوان حسب المخزون
- سلة مع تحكم بالكمية
- خصومات (بإذن صلاحية)
- دفع نقدي/آجل/مختلط
- إتمام البيع بمعاملة ذرية

### 3. المبيعات
- قائمة الفواتير مع فلترة بالتاريخ
- تفاصيل الفاتورة + الأصناف
- مرتجعات بيع
- تقارير مفصلة

### 4. المشتريات
- فواتير شراء من الموردين
- دفع نقدي/آجل
- زيادة المخزون تلقائياً
- تحديث التكلفة المرجحة

### 5. المخزون
- **حركات المخزون**: سجل كامل لكل تغير (شراء، بيع، تسوية، مرتجع)
- **تسوية المخزون**: تعديل الكمية الفعلية
- **الجرد**: جرد كامل مع حساب الفروقات

### 6. العملاء والموردون
- إدارة كاملة (CRUD)
- كشف حساب تفصيلي (مدين/دائن/رصيد)
- سداد الديون
- حدود الائتمان

### 7. الصندوق
- حركات نقد كاملة
- مصروفات (9 تصنيفات)
- سحوبات (مالك، موظف، شخصي، أخرى)
- إيداعات
- إغلاق اليوم مع التسوية

### 8. التقارير
- **المبيعات اليومية**: تفاصيل شاملة
- **الصندوق**: افتتاحي + حركات + متوقع + فعلي + فرق
- **الأرباح**: Gross Sales → Net Sales → Gross Profit → Operating Profit
- **الديون**: العملاء والموردون
- **المخزون**: قيمة + ناقص + راكد

### 9. المستخدمون والصلاحيات
- إدارة المستخدمين
- إدارة الأدوار والصلاحيات
- تفعيل/تعطيل
- إعادة تعيين كلمة المرور

### 10. الإعدادات
- بيانات المنشأة
- إعدادات المخزون (منع السالب، السماح بالدفع الزائد)
- إعدادات الضرائب
- الرصيد الافتتاحي للصندوق

### 11. النسخ الاحتياطي
- إنشاء نسخة JSON
- استعادة مع نسخة أمان
- حذف النسخ القديمة

## نظام الصلاحيات

### الأدوار الافتراضية

| الدور | الوصف |
|-------|--------|
| **المالك** | صلاحيات كاملة |
| **المدير** | العمليات + التقارير (بدون إعدادات حساسة) |
| **الكاشير** | مبيعات فقط |
| **المشتري** | مشتريات + موردون |
| **أمين المخزن** | مخزون + جرد |
| **المحاسب** | صندوق + ديون + تقارير |
| **مشاهد** | قراءة فقط |

### الصلاحيات حسب الوحدة

- **sales**: view, create, edit, delete, return, discount, change_price
- **purchase**: view, create, edit, delete, return
- **inventory**: view, edit, adjust, stocktake
- **customers**: view, create, edit, delete, payment
- **suppliers**: view, create, edit, delete, payment
- **cashbox**: view, create, adjust, close
- **reports**: view, profit, cash, debts, inventory
- **users**: view, create, edit, delete
- **settings**: view, edit
- **backup**: create, restore
